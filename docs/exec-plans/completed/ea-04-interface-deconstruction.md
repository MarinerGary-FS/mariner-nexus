# Experience Amplification 04 — Interface Deconstruction

## Phase objective

Transform the one intact Undugu Living Interface from visible client experience into a truthful, generalized Mariner operational model, preserving perceptual and semantic continuity throughout.

## Why this exists

EA-03 proves that the live client interface can adapt. EA-04 must show what Mariner Nexus understands beneath a meaningful action: intent becomes structured information, a configured system supports communication, a person acts, and the organization receives a useful outcome.

## Source of truth

- Canonical doctrine in `docs/mariner-nexus-redesign/`.
- DEC-030, DEC-031, DEC-038, DEC-040.
- Completed EA-03 plan and report.
- Global Typography & Content Integrity QA.
- User-authorized EA-04 Interface Deconstruction brief.

## In scope

- Extend the one mounted Undugu Living Interface beyond Responsive Performance into seven semantic deconstruction states.
- Use the authentic “Experience the Movement” action as the visible source signal.
- Progressively reveal Interaction, Intent, Structure, System, Notification, Human Action, and Useful Outcome.
- Make the Undugu-to-Mariner truth boundary explicit without claiming an Undugu backend implementation.
- Reintroduce Thread/Connection/Flow and Mineral Teal only as operational relationship/state.
- Independent desktop, tablet, mobile, reduced-motion, and JavaScript-free compositions.
- Expand canonical Content Integrity coverage and record material decisions.
- Review recording, static evidence, performance comparison, and completion report.

## Out of scope

- Homepage Systems refactor, Nexus amplification, objective-system changes, advanced graphics, WebGL, canvas, graph packages, AI capability, additional clients, real Undugu workflow claims, Production deployment, and EA-05.

## Required user experience

The final responsive composition remains visibly present. The intact interface expands, its authentic movement CTA becomes the source signal, and the surface separates only along meaningful conceptual boundaries. A restrained Thread originates at that action and resolves through a generalized Mariner operational model. Undugu identity recedes progressively while Graphite, Geist, and Mineral Teal assume systems authority. The sequence ends in human action and useful outcome, followed by the anchor statement: “The experience shouldn’t stop when someone clicks Submit.”

## Technical requirements

- Preserve one server-rendered interface and one logical DOM order.
- One route-local client controller may observe bounded semantic markers.
- No global scroll listener, per-frame React render, layout-measurement loop, request, new dependency, or continuous rendering.
- Connections are bounded decorative SVG/CSS; semantic meaning lives in HTML.
- Keep focus targets mounted and stabilize the source interface while it contains focus.

## Mobile requirements

Mobile begins with the recognizable interface, isolates its action, then reveals a vertical operational story. It must not shrink the desktop spatial diagram or start as a node list.

## Accessibility requirements

- Logical source-to-outcome reading order.
- The visual SVG is hidden from assistive technology.
- No stage is required to understand the complete server-rendered story.
- Focused controls remain usable and visually stable.
- Reduced motion uses immediate staged state changes.
- Without JavaScript, the intact interface is followed by the complete static operational model.

## Performance requirements

- Reuse the existing media and font strategy.
- No new media request or LCP change.
- Report JS, CSS, HTML, SVG, long-task, and layout-shift impact.

## Acceptance criteria

- The interface itself is the unmistakable origin of the revealed architecture.
- A nontechnical visitor can connect interface action to structured systems and human operation.
- The truth boundary distinguishes actual Undugu evidence from generalized Mariner capability.
- All seven deconstruction states remain readable and visually coherent.
- Engineering, Meaning, Impact, Content Integrity, Continuity, and Systems Intelligence gates pass.
