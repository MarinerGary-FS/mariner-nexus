## Architecture

The existing `NexusExperience` island owns three bounded release states after its peak: converged, resolving, and released. An Intersection Observer watches semantic scroll markers in a short sticky resolution boundary; no scroll listener, frame loop, measurement, lock, snap, or intercepted navigation is introduced. Once settled, all visual work is static. The following server-rendered conversion section owns the question, support, reassurance, and tracked `/start` link.
