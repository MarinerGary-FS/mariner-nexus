# EA-03 / EA-04 Comparison

## EA-03

The one semantic Undugu Living Interface visibly reorganizes navigation, typography, imagery, actions, and sequence as its available canvas changes. The capability proved is responsive intelligence.

## EA-04

The same mounted interface remains the source object. Its authentic “Experience the Movement” action becomes significant; client surfaces separate along meaningful boundaries; Interaction, Intent, Structure, System, Notification, Human Action, and Useful Outcome emerge from that source; Undugu identity then yields to Mariner systems language.

The difference is architectural: EA-03 changes the interface’s composition, while EA-04 makes the interface itself become the evidence for what Mariner understands beneath visible interaction.
