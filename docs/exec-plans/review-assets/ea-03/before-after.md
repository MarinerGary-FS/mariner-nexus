# EA-02 / EA-03 capability comparison

## EA-02 — Living Interface

One semantic Undugu interface is live inside the transformation record. It responds normally to the browser viewport through its authored desktop, tablet, and mobile CSS.

## EA-03 — Responsive Performance

The Mariner host now controls a bounded canvas while the browser remains unchanged. The same mounted Undugu navigation, hero message, image, and CTA group visibly move through Wide, Compressing, Intermediate, Reorganizing, Narrow, and Settled compositions. Container queries—not images or duplicate component trees—change navigation architecture, column count, line breaks, image relationship, CTA arrangement, padding, and sequence.

The capability difference is direct: EA-02 contains a responsive interface; EA-03 lets the visitor watch that interface think responsively.
