# Previous vs amplified Nexus

## Before EA-05

The Phase 06 Nexus used a two/four-column tab rail, one heading, straight SVG lines, uniformly weighted rectangular nodes, and a light environmental release. Objective changes moved nodes but retained the visual character of an explanatory architecture chart. The Mariner mark had no structural role and the homepage Systems demonstration ended before Nexus began.

## After EA-05

The Nexus is now a bounded architectural environment. The Systems outcome enters through a visible Experience → System → Useful Outcome seam; the four objectives change topology, spatial center of gravity, contextual capability, and organizational result; curved paths and a convergence axis communicate relationship; persistent core nodes carry trust; mobile becomes a distinct vertical architecture; and the section settles into a dark Mariner peak without release or conversion.

This is not the same visualization with refined styling. The control architecture, initial state, relationship geometry, depth model, responsive choreography, endpoint, continuity, fallback, and emotional role all changed.
