# Mariner Nexus Unique Website Funnel System

## Purpose

This system turns every client website into a custom-built digital experience instead of a duplicated template. The goal is to collect deep client intelligence, translate it into strategic markdown build files, feed those files into Codex, and run structured review cycles until the website feels impossible to confuse with anyone else’s.

This is not a template system.

This is a client-specific website intelligence pipeline.

---

# 1. Core Funnel Overview

## Funnel Stages

1. **Client Discovery Intake**
   - Collect business, audience, brand, visual, content, offer, funnel, and operational data.

2. **Strategic Synthesis**
   - Convert raw intake answers into a clear creative/business direction.

3. **Client Website Build Pack Generation**
   - Generate all required `.md` files for Codex.

4. **Codex Build Execution**
   - Use the build pack to create the website.

5. **V1 Client Presentation**
   - Present the first version with strategic reasoning.

6. **V2 Feedback Loop**
   - Collect client feedback using a structured review form.

7. **V3 Refinement Loop**
   - Tighten messaging, visuals, conversion logic, mobile, speed, and polish.

8. **Final Authority Pass**
   - Run final QA, performance, responsiveness, SEO, accessibility, analytics, and launch checks.

## Form Name

**Mariner Nexus Website Intelligence Intake**

## Form Description

This form helps us understand your business, audience, brand, offers, goals, visual preferences, and operational needs so we can build a custom digital experience designed specifically for you. The more honest and detailed your answers are, the more powerful the final website will be.

# 12. Operating Rule: Never Duplicate

Every client build must include a **Uniqueness Lock**.

## Uniqueness Lock Questions

Before development begins, answer:

1. What is the unique world of this brand?
2. What visual language belongs only to this client?
3. What motion behavior supports this client’s personality?
4. What content structure matches this client’s audience psychology?
5. What conversion path matches this client’s business model?
6. What should we avoid because it feels copied, trendy, or generic?
7. What is the signature moment visitors will remember?

If these questions cannot be answered, the project is not ready for Codex.
