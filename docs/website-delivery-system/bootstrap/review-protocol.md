# Review Protocol

Every bootstrap output defines Vercel Preview as the review environment without creating a deployment. The generated protocol states current stage, current review subject, what remains non-final, consolidated-feedback expectations, required approval, and the six change classes.

Checkpoint depth is proportional. Essential/restrained work receives strategy/content, core experience, release candidate, and protected Production checkpoints. Connected or Signature work adds relevant visual foundation, integration, signature-experience, and Preview checkpoints.

Feedback must be consolidated into one internal record and classified before Codex revision. No new review platform or paid service is introduced.
