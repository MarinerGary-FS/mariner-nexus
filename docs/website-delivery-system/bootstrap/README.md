# Kernel-Driven Project Bootstrap

WDS Bootstrap compiles a valid Project Kernel into proportional governance and planning artifacts. It creates the controls needed to start delivery; it does not generate a website, creative solution, client copy, price, adapter, credential, or deployment alias.

## Commands

```sh
npm run wds:bootstrap -- tools/wds/fixtures/restrained-professional /safe/new/target
npm run wds:check-bootstrap -- tools/wds/fixtures/restrained-professional /safe/new/target
```

The compiler validates shape and all semantic invariants before writing. Invalid input exits non-zero. Output includes concise operating rules, generated register views, one current-stage plan, proportional strategy/QA/operations obligations, review protocol, evidence directories, normalized artifacts, and a hashed bootstrap manifest.

No application shell is generated in WDS-03. Governance portability needed proof before choosing a framework scaffold; a neutral technical shell remains a later controlled decision.

## Proportional output

Core governance exists for every project. Conditional files appear only when the Kernel justifies them: experiential research and advanced-experience QA for A3/A4, elevated review for HIGH/CRITICAL risk, payment readiness for payment exposure, and formal release gates when release certification is required.

The restrained fixture therefore has fewer files and obligations than the immersive fixture while retaining truth, accessibility, responsive, release, and ownership controls.
