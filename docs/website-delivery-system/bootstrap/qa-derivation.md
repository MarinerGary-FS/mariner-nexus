# QA Derivation

The compiler renders the Kernel QA manifest rather than inventing a universal check count.

- Every project receives its required gates, accessibility obligations, browser states, responsive widths, and a transferred Content Integrity scaffold.
- HIGH/CRITICAL risk receives an elevated-risk review artifact.
- A3/A4 receives advanced-experience and experiential-research obligations.
- Payment exposure receives payment-readiness obligations.
- Formal release-gate documentation appears only when release certification is required.

The Content Integrity scaffold allows later declaration of routes, critical headings, controls, responsive states, identity states, and dynamic states. Its final matrix size emerges from implemented scope; the reference project’s check count is never a default.
