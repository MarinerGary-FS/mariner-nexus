# Mariner Nexus Reference Implementation Observations

These are evidence observations from ARC-01, not a Website Delivery System design or implementation.

WDS-01 promotes these observations into the traceable architecture documents under this directory. The Production site remains a reference implementation rather than a visual or procedural template.

- Content Integrity was most valuable as a permanent minimum matrix. It caught responsive text and state failures that route-level screenshots alone could miss; visual typography review remained necessary for intention and rhythm.
- Accessible-name checks caught real defects when control purpose text replaced the visible label. Visible label inclusion should remain a release gate.
- Project identity boundaries generalized well for lifecycle and isolation, while each world's typography, color, media authority, geometry, and choreography required authored judgment.
- Server-rendered semantic content plus small progressive-enhancement controllers produced useful JavaScript-free and reduced-motion behavior without parallel experiences.
- Responsive behavior generalized as shared containment, stable DOM order, and no horizontal overflow. Mobile choreography remained project- and section-specific.
- Truth boundaries prevented live-site observations from becoming unsupported transformation claims. Authorization and factual status must remain typed, reviewable inputs.
- Amplitude control required whole-journey review. Individual sections could pass alone while weakening Corporate → Range → Systems → Nexus → Release → Conversion when viewed together.
- Synthetic performance needed repeated measurement and human interpretation. LCP variance without CLS, long tasks, or runtime errors should lead to RUM observation, not automatic removal of approved expression.
- Native Safari review caught confidence gaps that Chromium automation could not close. Browser availability exceptions must remain explicit rather than silently treated as coverage.
- Codex could automate route, integrity, metadata, response, and state matrices; human judgment remained essential for visual hierarchy, identity authority, amplitude, truthfulness, and whether optimization preserved the approved experience.
- The pre-existing `mariner-nexus-delivery-system/` package demonstrates the risk of extracting structure before distinguishing doctrine from project expression: it copied Mariner-specific specification paths and phases into a generic template.
- Proportional rigor must be explicit. Universal quality does not require every engagement to repeat nineteen stages, every browser state, or advanced-experience certification.
- Provider defaults and recurring services are separate decisions. A technically useful service is not automatically a justified business expense.
