# Approval Register

Approval classes are:

- `A` — Autonomous
- `B` — Implement Then Review
- `C` — Approval Before Implementation
- `D` — Owner-Protected

Records retain subject, current class, minimum class, state, approver, and truth dependencies. The validator rejects class downgrade and approved decisions that depend on Required Input.

Production promotion, recurring paid services, credentials, destructive operations, public case-study authorization, material legal claims, and sensitive integrations are Owner-Protected. Automation may prepare evidence but cannot supply the approval.
