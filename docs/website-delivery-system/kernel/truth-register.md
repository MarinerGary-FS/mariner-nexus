# Truth Register

Each record has an ID, subject, exact statement, state, evidence/source reference, public eligibility, approver, and notes.

States are exactly `VERIFIED`, `CLIENT-PROVIDED`, `INFERRED`, `RECOMMENDED`, `REQUIRED INPUT`, and `PROHIBITED CLAIM`.

Only approved `VERIFIED` and `CLIENT-PROVIDED` facts may be public factual copy. Inferred material remains distinguishable; Required Input blocks dependent approval; prohibited claims are never public. Truth does not itself grant publication authorization.
