# Authorization Register

Supported categories are public display, case-study publication, logo usage, testimonial usage, metric usage, asset usage, and Production promotion. Each record states scope, state, approver, and date/evidence reference.

A `PUBLISHED` case-study route must reference an approved case-study authorization. Held or draft routes cannot enter the sitemap. Production promotion remains a separate Owner-Protected action; neither truth nor route configuration can manufacture permission.
