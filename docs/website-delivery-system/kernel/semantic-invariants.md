# Semantic Invariants

The validator currently enforces 20 blocking invariant classes:

1. Prohibited claims cannot be public.
2. Required Input cannot be public.
3. Inferred statements cannot automatically be public facts.
4. Public truth requires an eligible truth state.
5. Public routes cannot reference non-public truth.
6. Published case studies require approved case-study authorization.
7. Held/draft routes cannot be sitemap eligible.
8. Production promotion uses approval class D.
9. Recurring paid services require owner approval.
10. Secret integrations declare environment handling.
11. Data-collecting integrations declare classification and owner.
12. Critical risk requires elevated QA or approved override.
13. A4 cannot automatically require rendering technology.
14. Required browser coverage cannot be absent.
15. Browser non-blockers require permission and rationale.
16. Every operational area has an assigned owner.
17. Production readiness requires approvals.
18. Production readiness requires passing mandatory gates.
19. Approval class cannot be downgraded below its minimum.
20. Approval cannot pass while dependent truth is Required Input.

Shape validation runs first. Semantic checks run only on structurally valid input so failures remain precise. Subjective beauty, impact, identity fidelity, and creative memorability remain human judgments.
