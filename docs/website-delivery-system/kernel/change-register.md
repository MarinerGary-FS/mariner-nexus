# Change Register

Classifications are `CORRECTION`, `CONTENT_REVISION`, `DESIGN_REVISION`, `SCOPE_EXPANSION`, `ARCHITECTURE_CHANGE`, and `POST_APPROVAL_CHANGE`.

Each record captures requester, description, scope impact, approval requirement, affected milestone, and status. It governs revision and traceability; it contains no billing logic. Client feedback is consolidated into this internal classification before Codex implementation.
