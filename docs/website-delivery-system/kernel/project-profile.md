# Project Profile

`project.yaml` owns structured configuration; Markdown owns reasoning. The profile includes:

- identity: ID, name, organization, project type, public URL, repository context;
- delivery: tier, lifecycle stage, optional target, required approvals;
- objectives, audiences, success criteria;
- experience principles, emotional goals, amplification, responsive expectations;
- public/protected routes and redirects;
- governed actions and approval classes;
- hosting and seven operational responsibility areas;
- independent risk level, flags, and required reviews.

Delivery tiers are Essential Presence, Strategic Experience, Connected Experience, and Signature System. Amplification is independently A0 Functional through A4 Signature. Neither implies price or rendering technology. The Kernel contains no quote, rate, proposal total, markup, or maintenance pricing.

The JSON Schema uses `additionalProperties: false` at governed boundaries so misspellings and accidental fields fail instead of disappearing. `schemaVersion` is currently `1.0.0`.
