# Delivery Orchestrator Reference Routing

In WDS Mode, locate the project repository root and read `docs/website-delivery-system/skills/README.md` when present. Otherwise route through the project-generated `AGENTS.md`, `.wds/normalized-project.json`, active plan, Required Input view, review protocol, and Kernel truth/authorization/approval records. In Pre-Kernel or Legacy Mode, use repository authority and explicit instructions; never pretend project-local WDS references exist. Engineering implementation doctrine belongs to the Engineering Executor.
