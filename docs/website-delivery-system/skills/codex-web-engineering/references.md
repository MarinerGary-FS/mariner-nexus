# Engineering Executor Reference Routing

In WDS Mode, locate the project repository root and read `docs/website-delivery-system/skills/README.md` when present. Otherwise consume project-generated `AGENTS.md`, `.wds/normalized-project.json`, the active plan, QA/browser artifacts, integration registry, and operations plans. Do not resolve doctrine relative to the global Skill installation directory.

In Pre-Kernel or Legacy Mode, use repository authority and explicit instructions. Delivery lifecycle and approvals remain owned by the Delivery Orchestrator.
