# Evidence Policy

Evidence and assertions are different:

- visual/identity/impact claims require human review evidence;
- browser PASS requires execution in that browser;
- Production PASS requires Production verification;
- truth/publication PASS requires evidence plus authorization;
- performance PASS requires measurement;
- automated engineering PASS never manufactures a human gate approval.

Review handoff reports implemented and excluded scope, automated and human gates, commands/results, evidence locations, unresolved items, commit/deployment status, and precise stop condition.
