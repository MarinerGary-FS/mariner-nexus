# Bounded Adoption Pilot Protocol

The pilot uses a separate, non-client repository for fictional Emberline Pottery Cooperative, a community pottery studio with an identity and audience unrelated to Mariner Nexus.

The authorized chain is:

> Validated Kernel → Bootstrap → installed Skills → controlled assignment → homepage foundation → QA → human review stop

Scope is one dependency-free static homepage. Secondary routes, inquiry transport, integrations, credentials, deployment, Production, full-site delivery, framework generation, and lifecycle advancement are excluded. The public copy may use only approved fictional Kernel truth. Responsive evidence is required at 360, 768, and 1280 pixels; unavailable browsers are not passed. Completion must emit **IMPACT — HUMAN REVIEW REQUIRED**.
