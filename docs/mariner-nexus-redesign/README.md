# Mariner Nexus Redesign — Source of Truth

This directory is the canonical specification for the Mariner Nexus website redesign.

## Objective

Build a corporate-grade digital experience that progressively reveals Mariner Nexus's increasingly sophisticated capabilities while remaining easy to understand, fast, accessible, and operationally maintainable.

The visitor should leave asking:

> What could Mariner Nexus do with what I am trying to create?

## Governing principles

- Simple navigation. Deep experience.
- Serious before spectacular.
- Complexity should be discovered, never imposed.
- Experience-based. Strategy-led. Solution-specific.
- Adaptable by design.
- The website itself is part of the proof.
- The solution adapts to the organization; the organization does not adapt to our template.
- Technical sophistication should be experienced before it needs to be explained.
- The system listens.
- No buffering.
- Corporate Discipline × Creative Ambition.
- Neutral colors describe environment. Signal color describes activity. Client color describes identity.
- The technology disappears behind the experience.
- Earn complexity.
