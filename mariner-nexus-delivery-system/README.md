# Mariner Nexus Website Delivery System

A reusable operating system for strategy-led, experience-based, solution-specific website delivery using ChatGPT/Codex, GitHub, and Vercel.

## Package contents

- `skills/website-delivery/` — reusable client-delivery workflow.
- `skills/codex-web-engineering/` — reusable Codex implementation and QA workflow.
- `repo-template/AGENTS.md` — short repository-level operating doctrine.
- `repo-template/docs/mariner-nexus-redesign/` — project-specific source of truth for the Mariner Nexus redesign.
- `repo-template/docs/exec-plans/` — active/completed execution-plan structure.
- `repo-template/docs/mariner-nexus-redesign/decisions.md` — durable decision log.
- `repo-template/docs/exec-plans/active/phase-01-foundation.md` — first implementation brief.

## Operating model

The reusable system separates four concerns:

1. **Client truth** — objectives, audience, constraints, existing systems, and desired outcomes.
2. **Experience architecture** — what the visitor should understand, feel, and do.
3. **Engineering execution** — how Codex implements the approved specification.
4. **Validation** — visual, responsive, accessibility, performance, functional, and production review.

The reusable skills encode quality and process. They do **not** impose Mariner Nexus's visual identity on client projects.

## Core doctrine

- Experience-based.
- Strategy-led.
- Solution-specific.
- Adaptable by design.
- Business before interface.
- Complexity should be discovered, never imposed.
- Serious before spectacular.
- The technology disappears behind the experience.
- The system listens.
- No buffering.
- Earn complexity.

## Recommended adoption

Check the two skill folders into the appropriate Skills location for ChatGPT/Codex, or install them through the Skills interface. Copy `repo-template/AGENTS.md` and the relevant documentation structure into each repository.

For client projects, create a client-specific project specification under `docs/project-spec/` while retaining the reusable skill behavior.
