# 05 — Experience Architecture

## Core doctrine

> Serious before spectacular.

> Complexity should be discovered, never imposed.

> Mariner Nexus should never reveal its full capability at once.

## Depth model

### Understand
A skimming visitor understands the company and path to action without interaction.

### Explore
An interested visitor discovers responsive interactions, diagrams, work, and deeper proof.

### Investigate
A researcher/internal champion can enter case studies, live projects, architecture, methodology, and technical depth.

## Homepage emotional architecture

Arrival → Trust.

Recognition → Relevance.

Strategy/Nexus model → Intelligence.

Experience → Desire.

Work → Credibility.

Systems → Capability.

Nexus → Surprise.

Approach → Confidence.

Possibility → Imagination.

Start → Action.

## Complexity curve

Restraint → Expression → Structure → Peak → Restraint.

The site should feel musical: tension, expansion, peak, release.

## Key moments

### Arrival
Bright, restrained, precise.
Reaction:
> This is a serious company.

### Recognition
Show Create/Evolve/Transform situations without requiring those internal labels.

### Strategy model
Introduce the visual grammar of connection.

### Experience
Creative range increases. Client/project identity may temporarily take over.

### Proof
Final product dominates. Minimal explanatory text.

### Experience → Systems
A signature transition. The visible interface deconstructs into what happens behind it.

Culminating line:
> The experience shouldn't stop when someone clicks Submit.

### Systems
Graphite/dark, architectural, operational, not cyberpunk.

### Nexus
Peak creative/technical expression after trust is earned.

### Reassurance
Motion and density reduce. Corporate discipline returns.

### Possibility
Create self-projection:
> What could yours become?

### Conversion
Return to light. One decision:
> What are you trying to create?
> You don't need to arrive with the solution figured out.
> Start a Project →

## Motion purposes

Motion must serve:
- orientation,
- relationship,
- emphasis,
- expression.

Expression is used least.

## Performance

No buffering.
Advanced features lazy-load and may not block content/navigation.

## Responsive

> Responsive doesn't mean resized.

Mobile receives its own choreography and retains message parity without requiring identical effects.

## Interaction

> The system listens.

Hover, click, tap, select, and navigation changes provide immediate perceptual acknowledgment.
