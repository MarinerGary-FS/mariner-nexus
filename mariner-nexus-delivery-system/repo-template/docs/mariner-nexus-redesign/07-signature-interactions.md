# 07 — Signature Interactions

## Rule

An interaction must:
- explain Mariner Nexus,
- demonstrate capability,
- improve comprehension,
- improve navigation,
or materially improve the experience.

Otherwise remove it.

## 1. The Nexus — Flagship

A responsive system visualization demonstrating that different objectives require different architectures.

Begin with DOM/SVG.

It must:
- support objective selection,
- reorganize meaningful nodes rather than merely respawn them,
- expose concise explanations,
- visually demonstrate adaptability,
- work by keyboard,
- have a reduced-motion mode,
- have a mobile vertical interpretation.

Peak reaction:
> Time to blow them away.

## 2. Client Identity Takeover — Major

The neutral Mariner environment temporarily yields to the project's visual identity.

Demonstrates:
> We do not force clients into our aesthetic.

## 3. Experience → Systems Deconstruction — Major

A polished frontend interaction deconstructs into:
experience → interaction → validation → data → system → operation.

Culminates:
> The experience shouldn't stop when someone clicks Submit.

Reaction:
> They're not just a design studio.

## 4. Contextual White-Glove Navigation — Supporting

Navigation subtly reflects the visitor's current environment/section.

Purpose:
> The interface quietly knows where you are.

## 5. Work Portal — Supporting

Finished project presentation expands in dominance and leads into:
case study → live experience.

Credibility chain:
> See it → Understand it → Experience it live.

## 6. Responsive Transformation — Supporting

Where appropriate, demonstrate one living interface changing its composition instead of showing device mockups.

Proves:
> Responsive doesn't mean resized.

## Signal System — System-wide language

Mineral Teal:
REST → ACTIVE → SIGNAL → SETTLE.

Meaning:
> The system heard you.

## Mariner Thread — Recurring signature

A semantically meaningful connection motif may recur across Strategy, Experience, Systems, Nexus, Approach, and conversion.

Rule:
> Semantic or remove it.

It may not become a decorative scroll progress bar.

## Prohibitions

- custom cursor,
- scroll hijacking,
- fake loading screen,
- particle universe,
- mandatory horizontal scroll,
- sound effects,
- enter-experience splash,
- hidden navigation,
- interactions requiring instructions,
- novelty without purpose.
