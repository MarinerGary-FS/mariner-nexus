# 06 — Visual System

## Governing doctrine

> Mariner Nexus owns the frame. The work transforms the canvas.

> We don't decorate complexity. We reveal structure.

Visual signature:
> Connection.

## Color semantics

> Neutral colors describe the environment. Signal color describes activity. Client color describes identity.

### Environment family
- Nexus White.
- Silver.
- Structural Gray.
- Graphite.
- Nexus Black.

Exact production values are selected and contrast-tested in-browser.

### Signal family
Mineral Teal with functional states:
- REST.
- ACTIVE.
- SIGNAL.
- SETTLE.

Do not treat teal as a large decorative brand fill.

### Client identity
Client color systems may temporarily replace the Mariner signal language within project presentation, then transition back to Mariner Nexus.

## Typography

Two-family maximum:
- modern corporate sans/grotesk for primary interface and information,
- restrained editorial counterpoint for selective expressive moments.

Never fashion-magazine styling.

Use fluid type scaling and load only necessary weights.

## Grid

12-column desktop foundation.

Narrative behavior:
- Corporate → structured.
- Experience → loosened.
- Systems → structure exposed.
- Nexus → structure transformed.
- Approach → structure restored.

## Spacing

Generous architectural whitespace.

Density changes intentionally across the journey and follows the musical experience curve.

## Materiality

Architectural, restrained:
- hairline borders,
- subtle depth,
- controlled geometry,
- limited radii,
- minimal shadow.

Avoid generic SaaS card language.

## Imagery

Priority:
1. Real client assets.
2. Purpose-built interface/project media.
3. High-quality royalty-free imagery only when genuinely needed.

Avoid stock-corporate theater and generic AI-generated humans.

## Project presentation

No laptop-mockup parade.

Present the experience directly on the canvas.

Allow client identity takeover.

## Systems grammar

- Node.
- Connection.
- Flow.
- State.
- Pulse/Signal.

## Nexus

Meaningful dynamic architectural diagram.
No floating network sphere or decorative particles.

## Light-to-dark narrative

Light = surface/business/clarity.
Dark = systems/depth/architecture.
Return to light = process/confidence/action.

## Motion

Measured.
Precise.
Responsive.
Controlled.

No springy/cute/game-like default motion.

## Explicit bans

- generic AI gradients,
- purple/blue glow blobs as default identity,
- endless rounded SaaS cards,
- giant pill-button system,
- fake terminals,
- decorative code,
- stock boardrooms/handshakes,
- meaningless particles,
- scroll hijacking,
- forced preload experiences,
- gratuitous parallax,
- hidden navigation,
- animation without purpose.
