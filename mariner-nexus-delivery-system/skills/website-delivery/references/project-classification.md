# Project Classification

## CORE

Capabilities generally safe to sell and deliver with the standard workflow:

- Custom marketing/corporate/professional websites.
- High-fidelity responsive experiences.
- Landing experiences.
- Information architecture.
- UX/UI.
- Content presentation.
- Standard forms and structured data collection.
- Content systems appropriate to project scope.
- Standard scheduling integrations.
- Standard payment integrations.
- Analytics implementation.
- Vercel deployment and domain launch.

## SCOPED

Require explicit technical and operational evaluation before commitment:

- CRM integrations.
- Third-party APIs.
- Client portals.
- Custom dashboards.
- Significant authentication.
- Custom database architecture.
- Complex data migrations.
- Advanced Three.js/WebGL/WebGPU.
- Significant e-commerce.
- Multi-system automation.
- Anything that creates ongoing production support obligations.

Evaluate:
- documentation quality,
- security model,
- failure modes,
- vendor stability,
- data sensitivity,
- maintenance burden,
- client support expectations,
- rollback path,
- cost.

## OUT

Do not sell by default:

- Paid advertising management.
- Social media management.
- Full-service marketing retainers.
- Enterprise IT.
- 24/7 managed infrastructure.
- Enterprise ERP transformation.
- Large-scale CRM implementation.
- Enterprise cybersecurity operations.
- Generic developer staff augmentation.
- Training custom foundation models.
- Custom AI transformation consulting.
- Mission-critical financial infrastructure.

## Governing rule

Automation and agentic engineering may expand what the studio can build faster than they expand what the studio should agree to maintain.

Protect maintenance capacity.
