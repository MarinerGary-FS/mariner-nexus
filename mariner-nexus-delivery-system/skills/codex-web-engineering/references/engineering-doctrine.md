# Engineering Doctrine

1. The approved specification outranks implementation convenience.
2. The technology must disappear behind the experience.
3. Server by default.
4. Client only when interaction requires it.
5. Static/cached when possible.
6. Progressive enhancement.
7. No buffering.
8. No fake loading screens.
9. No silent compromises.
10. No drive-by refactors.
11. Every dependency earns its place.
12. Mobile gets its own choreography.
13. Accessibility is architecture.
14. Performance is part of the brand.
15. Earn complexity.
16. If advanced graphics fail, the experience still succeeds.
17. Report conflicts; do not hide them.
18. Maintainability outranks cleverness.
