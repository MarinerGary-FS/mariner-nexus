# Phase Brief Template

## Phase objective
State one bounded outcome.

## Why this exists
Describe the user/business/experience purpose.

## Source of truth
List exact repository documents governing the work.

## In scope
Enumerate approved deliverables.

## Out of scope
Enumerate tempting adjacent work that must not be introduced.

## Required user experience
Describe observable behavior, not adjectives.

## Technical requirements
State stack, rendering, data, dependencies, and architectural constraints.

## Mobile requirements
Describe the mobile choreography explicitly.

## Accessibility requirements
Describe keyboard, semantic, focus, reduced-motion, and alternative representations.

## Performance requirements
Describe loading order, bundle constraints, interaction responsiveness, and fallback behavior.

## Acceptance criteria
Use testable statements.

## Validation
List exact commands and browser/device checks.

## Delivery report
Require the standard completion report.
